# AVC / HEVC / AV1 Main Profile：分块、参考帧与运动补偿详细对比

## 1. 比较范围与基本概念

本文比较 AVC / H.264 Main、HEVC / H.265 Main 与 AV1 Main Profile 的常规帧间编码工具。讨论重点是解码器如何从已解码参考图像生成预测块，以及编码器如何描述预测和残差。

| 标准 | 本文范围 | 默认格式 |
|---|---|---|
| AVC / H.264 | Main，profile_idc = 77 | 8 bit、4:2:0 |
| HEVC / H.265 | Main | 8 bit、4:2:0 |
| AV1 | Main，seq_profile = 0 | 8 bit、4:2:0 |

AV1 Main 也允许 10 bit 4:2:0 和单色；为便于横向比较，正文按 8 bit 4:2:0 说明。HEVC Main10、HEVC SCC、AVC High 等 Profile 的额外工具不并入对比。

帧间编码利用时间相关性：当前块通常与另一张已解码图像中的一个或多个区域相似。概念流程如下：

```text
选参考图像与参考区域
  → 依据运动矢量做亚像素插值，生成预测 P
  → 当前样本 X - 预测 P = 残差 R
  → 变换、量化并编码残差与预测语法
  → 解码端反量化、逆变换并重建 X̂ = P + R̂
  → 环路滤波并更新参考图像缓冲
```

规范描述的是码流语法和解码过程；运动搜索、候选剪枝、参考帧选择策略以及率失真优化方式由编码器决定。因此，下文所说的“可以选择”表示语法允许，并不表示编码器一定会使用该工具。

帧内预测对比见[帧内编码详细对比]({{< relref "intra-coding-comparison-main-profiles.md" >}})。

帧间残差变换和量化对比见[变换与量化详细对比]({{< relref "transform-quantization-comparison-main-profiles.md" >}})。

## 2. 总体差异一览

| 维度 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 基础编码区域 | 16×16 宏块及子宏块 | CTU / CU 与 PU | 64×64 或 128×128 Superblock 下的多形状块划分 |
| 帧间分区 | 16×16、16×8、8×16、8×8 等，8×8 下继续细分 | 2Nx2N、2NxN、Nx2N、NxN 和 AMP 非对称分区 | NONE、HORZ、VERT、SPLIT、T 形及四条带分区 |
| 参考图像组织 | 按 POC 与标记维护 DPB，再构建 L0 / L1 列表 | 每幅图像声明 RPS，构建 L0 / L1 列表 | 8 个参考槽映射到 LAST、GOLDEN、ALTREF 等语义引用名 |
| 运动矢量预测 | 相邻矢量中值等空间预测，另有 skip / direct | AMVP 或 merge 候选；skip 复用 merge 预测 | MV 候选栈、时间／空间候选及 global motion 等模式 |
| 运动矢量精度 | 亮度四分之一采样；4:2:0 下色度为八分之一采样 | 亮度四分之一采样；4:2:0 下色度为八分之一采样 | 亮度一般为四分之一采样，允许高精度 MV 时可用八分之一 |
| 亮度插值 | 6 抽头半采样滤波；四分之一位置由组合得到 | 8 抽头亮度滤波 | 多种可切换滤波器；按方向做分数采样插值 |
| 多参考合成 | B slice 可双向预测；支持加权预测 | B slice 双向预测、加权预测 | 可组合两个参考预测，也支持楔形／差异加权等 compound 模式 |

工具多少并不直接等于压缩率或解码速度。实际效果取决于内容、码率、编码器决策、并行配置和解码硬件。

## 3. 分块方式：宏块、四叉树与多形状叶块

### 3.1 AVC Main：宏块内逐步缩小分区

亮度宏块固定为 16×16。帧间宏块可使用以下主要形状：

```text
16×16
├─ 16×16
├─ 16×8 或 8×16
└─ 8×8
   ├─ 8×8
   ├─ 8×4
   ├─ 4×8
   └─ 4×4
```

每个分区通常有自己的参考索引和运动矢量（skip/direct 模式按规则推导）。4:2:0 色度分辨率是亮度的一半，因此同一个亮度运动矢量会按色度网格缩放，并应用对应的色度插值。

这种结构规则清晰，较小分区能跟踪局部运动，但在密集纹理或运动边界处，更多小分区也意味着更多语法和编码器搜索工作。

### 3.2 HEVC Main：CU 树与 PU 形状

HEVC 将图像切成 CTU，再通过 CU 四叉树递归细分。帧间 CU 选择预测单元 PU；CU 的模式和残差变换树 TU 是不同层次。常用帧间 PU 形状包括：

| PU 类型 | 几何形状 |
|---|---|
| 2Nx2N | 整个 CU |
| 2NxN / Nx2N | 水平或垂直二分 |
| NxN | 四个正方形子区，限于特定最小 CU 条件 |
| 2NxnU、2NxnD、nLx2N、nRx2N | 以 1:3 左右比例分割的非对称运动分区（AMP） |

AMP 允许编码器把 PU 边界贴近运动物体轮廓，但它有 CU 尺寸等使用条件。不能把 HEVC 的 CU 四叉树和 PU 分区当作同一棵树：CU 负责编码区域的递归划分，PU 负责预测区域，TU 负责残差变换区域。

### 3.3 AV1 Main：多种方形、矩形及组合分区

AV1 在 Superblock 树中选择叶编码块。分区除 NONE、HORZ、VERT、SPLIT 外，还包括 HORZ_A / HORZ_B、VERT_A / VERT_B、HORZ_4 / VERT_4。它们可以生成 T 形或四条带结构。具体尺寸与分区能否使用受块大小、边界和语法条件约束。

与 AVC 常见 1:2 子分区相比，AV1 的分区树能描述更多矩形与组合形状；与 HEVC 相比，它的分区语法和树形也不同。形状更多可以更贴合局部运动，但编码器要评估的合法组合和分区信令也更复杂。

**要点：**相同的“8×8”并不代表三种标准编码了同样的语法单位。比较块大小时要同时说明它是编码块、预测分区还是变换块。

## 4. 参考图像：怎样找到可用的过去与未来

### 4.1 AVC：DPB、POC 与显式列表管理

解码图像缓冲区（DPB）保存后续可能使用的参考图像。AVC 通过图像顺序计数（POC）、短期／长期参考标记、滑动窗口或记忆管理控制操作等机制管理图像，并为当前 slice 构建参考列表：

- P slice 使用参考列表 L0。
- B slice 可使用 L0 和 L1，列表可通过语法重排序。
- 一个分区的预测语法可指定参考列表索引；相邻块运动矢量预测会在相应参考条件下推导。

参考图像在解码与显示顺序中的关系并不总是“上一张显示的图像”。B 图像可引用显示时间上更晚、但已经先解码的图像；参考标记和解码顺序决定可用性。

### 4.2 HEVC：按当前图像声明参考图像集合

HEVC 使用参考图像集合（RPS）描述哪些短期和长期参考图像会被当前或后续图像使用。根据 RPS 和 slice 头信息建立 L0、L1 列表。B slice 可以从两个列表取预测，P slice 主要从 L0 取预测。

RPS 把“哪些图像保留／使用”与具体 PU 的“使用哪个列表项”分开描述。DPB 仍然需要保留规范要求的参考图像，但实际缓存大小受级别、图像尺寸、时序和配置约束。

### 4.3 AV1：槽位与语义引用名分离

AV1 有 8 个参考帧槽。帧头把语义名称（如 LAST、LAST2、LAST3、GOLDEN、BWDREF、ALTREF2、ALTREF）映射到槽位索引；块级语法再选择一个或两个引用名称。更新帧时，`refresh_frame_flags` 指示哪些槽被新重建帧刷新。

这种设计允许引用名称在不同帧间指向不同槽位，名称和实际存储槽并非固定绑定。AV1 也可以通过显示已有参考帧的方式避免再次编码图像内容。解码顺序、显示顺序和槽位更新共同决定可引用图像。

| 对照点 | AVC | HEVC | AV1 |
|---|---|---|---|
| 管理视角 | DPB 标记与 slice 列表 | RPS 与 L0 / L1 列表 | 固定数量槽位与引用名映射 |
| 块级引用 | 参考列表索引 | L0 / L1 索引 | 一个或两个引用帧名称 |
| 易错理解 | “前一显示帧就是列表 0” | “RPS 就是每块的参考索引” | “LAST 永远对应同一槽位” |

三种格式都会让编码器安排参考结构以平衡预测质量、随机访问、延迟和内存占用；标准不会规定某一段视频必须采用固定 GOP 模式。

## 5. 运动矢量：既描述运动，也要压缩运动信息

运动矢量 MV 指向参考图像中的预测位置。编码码流通常不直接重复发送每个块的绝对 MV，而是先由解码器从邻块或时间参考生成候选，再发送候选选择和差分（MVD）。

### AVC：中值预测、MVD 与 skip / direct

一般情况下，AVC 从当前分区左、上、右上邻近分区的 MV 推导中值预测值，再加上解码出的运动矢量差分。预测候选会受分区、参考图像索引和边界可用性影响。

B slice 的 direct 模式可利用空间或时间关系推导运动信息；P / B skip 模式省略显式残差或运动差分等语法，运动信息按规范推导。skip 不表示“宏块没有被编码”，而是它采用了一种高度压缩的预测表示。

### HEVC：AMVP 与 Merge 候选

HEVC 提供两种常见描述路径：

- **AMVP**：从空间或时间候选中选运动矢量预测值，再编码 MVD 和参考索引等信息。
- **Merge**：从候选列表中选一项，复用候选的预测方向、参考图像和 MV，不发送独立 MVD。Skip 可视为使用 merge 运动信息且没有非零残差的路径。

两条路径的语法差别可以这样对照：

```text
                      空间邻块 + 时间候选（colocated）
                                  │
                   ┌──────────────┴──────────────┐
                   │                             │
              AMVP 候选列表                  Merge 候选列表
             （只取 MVP 值）            （取 预测方向 + refIdx + MV 整组）
                   │                             │
      码流发送：                        码流发送：
        · mvp_l0/l1_flag  候选索引        · merge_idx  候选索引
        · ref_idx_l0/l1   参考索引
        · MVD             差分矢量
                   │                             │
            MV = MVP + MVD                 MV = 候选 MV（无 MVD）
                   │                             │
                   └──────────────┬──────────────┘
                                  │
                           运动补偿预测 P
                                  │
                   ┌──────────────┴──────────────┐
            有残差 → 编码残差              残差全零 → Skip
                                        （merge 运动信息 + 省略残差语法）
```

这让相邻块运动相似时可以用少量语法复用信息；若候选不合适，编码器仍可选 AMVP 路径发送差分。候选推导、去重和列表长度由规范约束。

### AV1：MV 候选栈、时间候选与多种运动模型

AV1 从邻近块及参考帧中的运动信息构建 MV 候选栈。块可按模式选择候选或发送与候选的差值。除了常规平移运动外，还有 global motion、局部 warped motion 等路径，用来描述更大范围或块级的变换运动；具体模式受块类型和语法条件控制。

AV1 还支持 OBMC（重叠块运动补偿）：在块边缘对相邻块的运动预测做加权混合，以减轻分块运动边界造成的突变。它会增加预测依赖和解码工作，并非所有块都启用。

### 运动矢量候选的差别

三种格式都会"从邻居那里借运动信息"，但借的方式差别很大。最根本的一点是：**它们对"候选列表"的定义并不相同**。

| 对照点 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 是否存在候选列表 | 没有列表，按规则推导出唯一预测值 | 两个定长列表：AMVP 2 项、Merge 最多 5 项 | 一个按权重排序的候选栈，最多 8 项 |
| 码流是否发送候选索引 | 不发送，解码器完全推导 | 发送：`mvp_l0/l1_flag`、`merge_idx` | 按模式发送 DRL 索引 |
| 空间候选位置 | 左 A、上 B、右上 C（C 不可用时用左上 D） | 左侧组 A0 / A1，上方组 B0 / B1 / B2 | 先扫描紧邻的上一行与左一列及右上角，再按条件扩展到更远的行列 |
| 候选组合方式 | 三个 MV 的水平、垂直分量各自取中值 | 每组最多取一个，去重后按固定顺序排列 | 相同 MV 的候选合并并累加权重（按与当前块的重叠长度），再按权重排序 |
| 时间候选 | 仅 B slice 的 temporal direct 使用 colocated MV | TMVP 单点：colocated 的 C0 右下，退化到 C1 中心，按 POC 距离缩放 | 运动场投影：把参考帧的 MV 投影到当前帧的 8×8 网格 |
| 补位候选 | — | B slice 的组合双向候选，再补零 MV | 额外搜索候选、global motion 候选，再补零 |

几个容易混淆的点：

- **AVC 的"中值"不是从列表里选一项**。它把 A、B、C 三个 MV 的 x 分量取中值、y 分量取中值，结果可能是三个候选里谁都没有的一个新矢量。16×8 / 8×16 分区还有专门的方向性推导规则，不走中值路径。
- **HEVC 的 AMVP 和 Merge 是两个不同的列表**，长度和内容都不同，不能当成"同一个列表的两种用法"。AMVP 只取 MVP 数值，Merge 取整组运动信息。
- **AV1 的候选栈是排序的**。权重来自候选邻块与当前块边界的重叠长度，所以"贴着当前块边更长的邻居"更可能排在前面。这和 HEVC 的固定扫描顺序不同。
- **时间候选的开关**：HEVC 由 `slice_temporal_mvp_enabled_flag` 控制，AV1 由 `use_ref_frame_mvs` 控制；关闭时两者都退回纯空间候选。

| 特性 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 常见运动描述 | 空间中值预测 + MVD | AMVP + MVD，或 Merge 复用候选 | 候选栈选择／差分，另有全局或 warped 模型 |
| 省略显式 MV 的路径 | Skip / Direct 推导 | Merge / Skip | 选择 MV 候选，部分模式结合 global motion |
| 邻块预测扩展 | 以相邻分区为主 | 空间候选与时间 MVP | 空间候选栈、时间候选及更丰富模式 |

### 亚像素精度不等于实际精度收益

AVC 与 HEVC 的亮度 MV 使用四分之一采样精度；AV1 亮度通常也是四分之一采样精度，并在允许高精度 MV（`allow_high_precision_mv`）的条件下可使用八分之一采样精度。更细精度让位置描述更细，但要发送 MV、执行插值，也可能让编码器搜索更慢。是否改善画质取决于信号、码率和 MV 量化等因素。

这里要区分亮度和色度：4:2:0 色度采样网格是亮度的二分之一，同一个 MV 换算到色度平面后，亮度的四分之一采样位移对应色度的八分之一采样相位。所以 AVC 和 HEVC 的色度插值本身就工作在八分之一采样精度上（AVC 双线性、HEVC 四抽头滤波各有 8 个相位），但这并不意味着亮度 MV 是八分之一精度。AV1 的八分之一采样指的是亮度 MV 精度模式，和 4:2:0 色度相位换算不是同一件事。

| 说法 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 亮度 MV 精度 | 1/4 采样 | 1/4 采样 | 1/4 采样；允许高精度 MV 时为 1/8 |
| 4:2:0 色度插值相位 | 1/8 采样（8 相位双线性） | 1/8 采样（8 相位四抽头滤波） | 由亮度 MV 按色度网格换算得到的分数相位 |

## 6. 运动补偿插值：亚像素位置如何生成预测

MV 常落在整数像素之间，解码器需用相邻参考样本插值得到预测值。滤波器影响画面细节、振铃、复杂度以及运动补偿结果，因此比较 MV 精度时也要看插值规则。

### AVC：固定亮度滤波器

AVC 亮度半采样位置采用 6 抽头滤波，滤波系数为整数并含规范舍入与裁剪；四分之一采样位置由整数／半采样预测组合产生。色度采用双线性插值，按色度分数位置计算。对于边界以外的参考坐标，要按规范的边缘扩展规则取样。

### HEVC：更长亮度滤波与四抽头色度滤波

HEVC 亮度分数位置使用 8 抽头插值滤波，色度使用 4 抽头滤波。滤波系数依分数相位而变，四分之一采样精度与这些相位配合。与 AVC 不同，HEVC 不只是把 AVC 的滤波器加长：相位、系数和整数实现都由 HEVC 规范单独定义。

### AV1：多种可选插值滤波器

AV1 提供 Regular、Smooth、Sharp、Bilinear 等插值选择，也可以对方向作 switchable 选择。具体语法控制块所用滤波器；某些工具路径和块条件会限制可用选择。滤波器仍需精确整数化实现，以保证不同解码器得到一致重建。

| 标准 | 亮度插值特点 | 色度插值概述 |
|---|---|---|
| AVC | 固定 6 抽头半采样滤波，四分之一位置由组合构造 | 双线性 |
| HEVC | 按相位的 8 抽头分数采样滤波 | 按相位的 4 抽头滤波 |
| AV1 | Regular / Smooth / Sharp / Bilinear 等选择 | 按 AV1 规定的分数采样插值处理 |

插值滤波器并不能单独决定压缩效率。编码器会联合搜索 MV、参考图像、滤波器、分区和残差；滤波器更贴合运动区域时可能降低残差，也可能增加语法成本。

## 7. 单向、双向与复合预测

### AVC 和 HEVC：P / B slice 与加权预测

P slice 主要使用一个方向的列表预测。B slice 可为分区分别从 L0、L1 取预测，也可把两个预测按规则组合。加权预测允许对预测样本施加权重和偏移；HEVC 也保留加权预测语法。

双向预测可利用两个时间方向的信息，但通常会带来额外参考读取和计算。若两个预测不相似或运动遮挡严重，编码器可能只选一个参考或选帧内模式。

### AV1：Compound 模式与遮罩融合

AV1 可将两个参考帧的预测组合为 compound prediction。除基本平均外，还能使用距离加权、楔形（wedge）或差异加权等遮罩，让两路预测在块内不同位置占不同权重。它可更精细地表达遮挡边界，但通常需要相应的遮罩语法和两路预测计算。

AV1 的 compound prediction 由引用帧类型、帧头工具开关和块语法共同控制，不能简单概括为“每块都能使用任意两个参考”。

## 8. 残差与环路滤波：预测之后还有什么

预测块形成后，三种格式都会对残差进行变换／量化／熵编码。帧间预测块的残差变换可比帧内预测更灵活，且与编码块和预测分区尺寸有各自约束；若块无残差或残差系数全零，可使用 skip 等省略路径。由于本文聚焦帧间预测，不展开具体变换系数扫描和量化规则。

解码器重建后的参考图像需应用标准规定的环路滤波，之后可用于后续图像预测。这里有一个容易忽略的闭环：当前图像的预测依赖过去图像的重建结果，因此如果编码器和解码器使用不同的 MV 精度、插值、残差舍入或滤波结果，后续图像就会产生预测漂移。规范通过明确整数运算和处理顺序避免这种差异。

| 环路滤波 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 去块滤波 | 有，按边界条件处理块效应 | 有，作用于适用的 PU / TU / CU 边界 | 有，按帧／块语法控制 |
| 第二类滤波 | — | SAO，按区域补偿重建样本偏差 | CDEF，抑制振铃并保留边缘 |
| 后续恢复滤波 | — | — | Loop Restoration，可按区域选择修复滤波 |

AV1 的 CDEF 和 Restoration 与运动插值不是同一步骤：它们作用于重建图像，影响后续图像可引用的参考内容。滤波工具开关、边界和处理顺序必须遵循码流定义。

三种标准环路滤波工具的原理、参数粒度和设计取舍详见[AVC / HEVC / AV1 环路滤波详细对比]({{< relref "loop-filter-comparison-main-profiles.md" >}})，包括 HEVC SAO 与 AV1 CDEF / Loop Restoration 的差异。

## 9. 同一场景下的编码选择示例

以下是编码器可能采用的策略示例，不是规范强制规则，也不表示每次都能节省码率。

### 场景 A：静态背景上有一个快速移动的小物体

AVC 可细分到 8×4 或 4×4 子分区，逐块描述运动。HEVC 可用小 CU、PU 或 AMP 分区贴近物体边缘。AV1 可用矩形或 T 形分区，再为部分块选择 compound 或遮罩预测。究竟选择哪种划分，还要比较额外分区语法与残差变化。

### 场景 B：整幅画面缓慢平移

三个标准都可使用大块和相近运动矢量。HEVC merge 或 AV1 MV 候选复用有机会减少重复 MV 差分；AV1 的 global motion 在适用内容下可描述较大范围变换。若运动并非整体一致，编码器仍可能选局部 MV。

### 场景 C：镜头切换或内容突变

过去参考帧不能有效预测新场景时，残差会增大，编码器可能选帧内块、刷新参考图像或调整 GOP。格式标准提供语法能力，但具体切换检测与参考策略属于编码器实现。

### 场景 D：慢动作与遮挡边缘

双向预测可能利用前后两侧信息；AV1 的 wedge / difference compound 可在块内区分两路参考。HEVC 和 AVC 可采用双向预测、局部小分区或帧内块来降低遮挡边界残差。收益依赖前后参考的质量和运动估计是否准确。

## 10. 如何比较实现成本与效果

根据工具结构可作以下工程推导，但它们不是标准保证：

| 层面 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 分区搜索 | 规则宏块子分区 | CU 树、PU 形状、AMP 和 TU 配合 | 多形状分区树与叶块组合 |
| 运动搜索 | 参考列表、MV、分区模式 | 增加 AMVP / Merge 及候选列表决策 | 候选栈、复合预测、global / warped 等更多选择 |
| 预测计算 | 固定半像素／四分之一位置滤波 | 多相位插值，双向路径 | 可选插值滤波、遮罩融合及可选运动模型 |
| 参考帧管理 | DPB 与列表重排 | RPS 与列表构造 | 8 槽刷新与引用名映射 |
| 环路滤波 | 去块滤波 | 去块与 SAO | 去块、CDEF、Restoration |

更复杂的模式集合可能帮助编码器在特定素材上降低残差，也会增加搜索和解码工作。实际对比应固定输入、目标码率或质量、GOP、线程、编码器版本和速度档，再观察码率、主观画质、编码时间、解码时间及内存占用。

## 11. 常见误区

| 容易误写的说法 | 更准确的说法 |
|---|---|
| 参考帧就是显示时间上的上一帧 | 解码顺序、显示顺序、列表／槽位管理共同决定可用参考 |
| 运动矢量是从当前块指向下一帧 | 它描述当前块在所选参考图像中的采样位移；参考可以来自不同时间方向 |
| 有四分之一像素 MV 就说明预测位置完全准确 | MV 精度只规定位置量化粒度，插值、估计误差和内容仍影响预测 |
| HEVC 的运动矢量是八分之一像素精度 | HEVC 亮度 MV 是四分之一采样精度；八分之一是 4:2:0 下色度插值的相位粒度，AVC 同理。AV1 的八分之一指的是亮度高精度 MV 模式 |
| HEVC 只有方形运动块 | 除方形外还有对称矩形与受条件限制的 AMP 分区 |
| 三种标准都是从候选列表里选一个索引 | AVC 没有候选列表，也不发送索引，预测值由规则推导；HEVC 发送 AMVP／Merge 索引；AV1 发送 DRL 索引 |
| AVC 的中值预测就是在三个候选里挑一个 | 它对 x、y 分量分别取中值，结果可能不等于任何一个邻块 MV |
| AV1 LAST 永远是固定槽位 | LAST 等语义引用名会映射到 8 个可刷新槽中的不同槽位 |
| B 帧就是把前后帧简单平均 | 两路预测还要结合分区、参考列表、权重和运动信息；AV1 还可使用遮罩融合 |
| Skip 表示这个块没有任何码流信息 | skip 仍有模式和上下文语法，只是省略部分 MV／残差等信息并按规则推导 |
| 工具更多必然码率更低、速度更慢 | 可用工具和搜索策略共同影响结果，需要在相同条件下测量 |
| 环路滤波只是显示后处理 | 环路滤波后的重建图像可能成为后续预测参考，属于解码闭环的一部分 |
