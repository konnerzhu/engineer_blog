# AV1、HEVC、AVC 的块划分区别

本文聚焦编码树／编码区域如何切块，以及这些块与预测、变换的关系。为避免把不同层级的“块”混为一谈，AVC 部分以常见的 8-bit 4:2:0 AVC Main 为例；HEVC 与 AV1 也以常见 Main 工具集说明。具体尺寸和可用划分会受 Profile、序列参数、色度格式及图像边界约束。

## 一句话概括

- **AVC：宏块为固定 16×16 亮度网格**，帧内可选整块 16×16 或拆为 4×4 预测块；灵活性主要在宏块内部。
- **HEVC：从 CTU 开始递归四叉树划分 CU**，再由预测单元（PU）和变换单元（TU）分别描述预测与残差；帧内预测区域以正方形为主。
- **AV1：从 64×64 或 128×128 Superblock 开始划分**，递归方形 SPLIT 之外，还可选水平、垂直、T 形及四条带分区，叶块形状更丰富。

## 结构对照

| 项目 | AVC / H.264 | HEVC / H.265 | AV1 |
|---|---|---|---|
| 顶层区域 | 16×16 亮度宏块（MB） | CTU，最大可到 64×64 亮度 | Superblock，64×64 或 128×128 |
| 编码树的基本方式 | 宏块网格固定；宏块内部按宏块类型组织 | CTU 递归四叉树得到 CU | Superblock 递归划分；SPLIT 可继续递归，其余划分产生子块 |
| 典型最细区域 | 帧内 4×4 预测块；宏块本身仍是 16×16 | 常见配置最小 CU 为 8×8；最小 CU 可使用 NxN 帧内 PU，例如四个 4×4 PU | 编码块最小可到 4×4 |
| 帧内矩形预测分区 | Main 不提供任意矩形帧内分区；有 16×16 与 4×4 两类亮度组织 | 帧内 PU 主要为 2Nx2N，最小 CU 可用 NxN；帧间矩形 PU 不等于帧内矩形 | HORZ、VERT、HORZ_A/B、VERT_A/B、HORZ_4、VERT_4 等提供矩形及 T 形叶块 |
| 编码块与变换块关系 | 宏块划分组织预测和残差；变换分块另有规则 | CU、PU、TU 分层独立；一个 PU 可包含多个 TU | 编码块和变换块是不同层级；不能由编码块尺寸直接推断一次变换的尺寸 |

## 各标准的划分方式

### AVC：固定宏块网格，宏块内选粒度

每个亮度宏块覆盖 16×16 样本。常见 Main Profile 帧内亮度模式可概括为：

```text
16×16 宏块
├─ Intra_16×16：整个宏块使用一个预测模式
└─ Intra_4×4：分为 16 个 4×4 区域，各自使用预测模式
```

所以 AVC 的适应性主要来自“宏块内部采用粗粒度还是细粒度”。AVC 帧间编码支持多种矩形宏块分区，但不能据此推断帧内也有相同的矩形划分。Intra_8×8 属于 AVC 支持该工具的其他 Profile，不属于本文 AVC Main 例子。

### HEVC：CTU 四叉树与 CU、PU、TU 分层

HEVC 用 CTU 取代固定 16×16 宏块。CTU 可按四叉树逐级拆为 CU；CU 再选择预测结构，残差则由 TU 划分：

```text
CTU
└─ CU 四叉树
   ├─ PU：预测模式及预测区域
   └─ TU 树：残差变换区域
```

帧内 CU 通常用一个 2Nx2N PU；在允许的最小 CU 层级可选择 NxN，分成四个正方形 PU。TU 可继续分割，因此 CU、PU、TU 的边界和尺寸不必完全相同。Main 的帧间 PU 还可使用矩形及非对称分区，但它们不是帧内 PU 形状。

### AV1：多种方形、矩形和 T 形分区

AV1 Superblock 可选不划分、水平／垂直二分、四分之一方形 SPLIT，以及其他非对称分区。AV1 规范列出 10 种分区类型：

| 类型 | 形状概念 |
|---|---|
| NONE | 保留为一个块 |
| HORZ / VERT | 沿水平方向 / 垂直方向二分 |
| SPLIT | 四个正方形子块；子块可继续递归划分 |
| HORZ_A / HORZ_B | 水平 T 形：一半再分成两个小块，另一半保持完整 |
| VERT_A / VERT_B | 垂直 T 形：一半再分成两个小块，另一半保持完整 |
| HORZ_4 / VERT_4 | 切成四条水平 / 垂直条带 |

AV1 的编码块形状覆盖正方形、1:2 / 2:1 及部分 1:4 / 4:1 长宽比。不是每个尺寸都允许全部分区，最小块、最大块和画面边缘均有约束。AV1 的丰富划分让编码器能更贴合长边缘或不对称区域，但也意味着分区搜索和语法决策更多。

## 帧内与帧间：同一标准里，划分规则也可能不同

下图用一个宏块／CU 说明常见亮度预测区域。图中的格子表示预测分区，不是变换单元（TU）。

### AVC：帧内 4×4 / 16×16，帧间另有矩形运动分区

```text
帧内 Intra_16×16       帧内 Intra_4×4        帧间常见分区
+------------------+   +--+--+--+--+         +------------------+ 16×16
|                  |   |  |  |  |  |         +------------------+
|   一个 16×16      |   +--+--+--+--+         +---------+--------+ 16×8
|   预测区域        |   |  |  |  |  |         +---------+--------+
|                  |   +--+--+--+--+         +----+----+----+----+ 8×8 子宏块
+------------------+   |  |  |  |  |         |    |    |    |    |
                       +--+--+--+--+         +----+----+----+----+
                       （16 个 4×4）          子宏块还可继续细分
```

帧内主要在 Intra_16×16 与 Intra_4×4 之间选择；帧间则可以按运动变化选择 16×16、16×8、8×16，或更小的子宏块分区。**帧间的矩形分区不表示帧内也能使用这些形状。** AVC 的具体帧间划分还依宏块类型而定。

### HEVC：帧内 PU 形状受限，帧间 PU 可矩形和非对称

假定一个 16×16 CU：

```text
帧内：2N×2N                   帧内：N×N（只在允许的最小 CU 层级）
+------------------+          +---------+---------+
|                  |          |  8×8 PU |  8×8 PU |
|    16×16 PU      |          +---------+---------+
|                  |          |  8×8 PU |  8×8 PU |
+------------------+          +---------+---------+

帧间：对称矩形                 帧间：非对称运动分区（AMP）
+---------+--------+          +----+-------------+
|         |        |          |    |             |
| 16×8    | 16×8   |          +----+-------------+
+---------+--------+          |    |             |
                              +----+-------------+
                              例如 1:3 / 3:1 子区
```

帧内 PU 通常是整个 CU 的 2Nx2N；只有在最小 CU 处可选四个 NxN 正方形 PU。帧间 PU 还可采用 2NxN、Nx2N、NxN 和 AMP（如 2N×nU、2N×nD、nL×2N、nR×2N）。CU 的四叉树仍可用于帧内和帧间；图中差异指 **CU 内部预测单元 PU 的形状**，不是说帧内 CU 不能做四叉树拆分。

### AV1：分区树形式相同，叶块分别选择帧内或帧间预测

AV1 的 Superblock 分区语法描述编码树的几何形状；划分后的叶块再使用帧内或帧间预测（受帧类型、块尺寸和语法约束）。因此 AV1 不像 HEVC 那样用一套帧内 PU 形状、另一套帧间 PU 形状来概括：其 HORZ、VERT、SPLIT、T 形、四条带等是树上的编码块分区选择。

```text
同一个 AV1 分区树（示意）
+-------------------------------+
|             上部              |
+---------------+---------------+  HORZ
| 左上  | 右上  |     下部      |  HORZ_A
+-------+-------+---------------+

分区叶块：可采用帧内预测                 分区叶块：也可采用帧间预测
+---------------+---------------+       +---------------+---------------+
| intra 模式    | intra 模式    |       | inter 参考帧  | inter 参考帧  |
| +方向/非方向  | +方向/非方向  |       | +运动信息     | +运动信息     |
+---------------+---------------+       +---------------+---------------+
```

AV1 的“分区树结构可以相同”不等于所有块都能任选所有分区类型：合法选项仍受块尺寸、边界和帧语法约束；叶块的帧内／帧间模式也由相应语法决定。

### 三者差异速览

| 标准 | 帧内预测分区 | 帧间预测分区 | 关键区别 |
|---|---|---|---|
| AVC | 16×16 或 4×4 亮度预测区域（Main） | 宏块可为 16×16、16×8、8×16、8×8 等，并可继续细分 | 帧内与帧间的宏块分区选择明显不同 |
| HEVC | CU 内通常为 2Nx2N；允许时可为四个 NxN | PU 可为 2Nx2N、2NxN、Nx2N、NxN，并可用 AMP | CU 树可共用，CU 内 PU 形状随帧内／帧间而变 |
| AV1 | 共享 Superblock 分区树；叶块用帧内模式 | 共享 Superblock 分区树；叶块用帧间模式 | 几何分区语法是编码树层级，预测类型由叶块语法表达 |

## 编码块、预测块、变换块：三层划分图

这三种块回答不同问题：

- **编码块**：语法和编码决策在哪个区域组织？
- **预测块**：哪一片区域共享一个帧内预测模式，或一组帧间运动信息？
- **变换块**：哪一片预测残差一起进行变换和量化？

用同一个区域分别画三种边界，更容易看出它们描述的是不同划分：

```text
编码区域 / CU       预测块             变换块
+---------------+   +-------+-------+  +-------+-------+
|               |   |       |       |  |       |       |
|   一个 CU     |   +-------+-------+  +-------+-------+
|               |   |       |       |  |       |       |
+---------------+   +-------+-------+  +-------+-------+
                    两行两列预测区     更细的残差变换区
```

图为概念示意，不表示这三种划分必须有相同的边界或固定尺寸比例；标准允许的尺寸组合因编码模式而异，预测块和变换块的边界也可能不重合。不要由“一个编码块”推断它只做一次预测或一次变换。

### 三种标准中三层关系的典型形态

```text
AVC（亮度示意）
宏块 16×16
└─ 帧内预测：Intra_16×16 一个模式区，或 Intra_4×4 的 4×4 模式区
   └─ 残差变换：以 4×4 变换块为基本网格（具体残差路径还含 DC 处理）

HEVC
CTU
└─ CU 四叉树
   ├─ PU：帧内/帧间预测区域（帧间 PU 可分矩形；帧内 PU 形状受限）
   └─ TU：残差变换树，可在 CU/PU 覆盖范围内再细分

AV1
Superblock
└─ 编码块分区树（NONE、SPLIT、矩形、T 形等）
   ├─ 叶块预测：帧内模式或帧间运动信息
   └─ 变换块：按变换尺寸及适用的变换分割规则覆盖残差
```

| 标准 | 编码块到预测块 | 预测块到变换块 | 观察重点 |
|---|---|---|---|
| AVC | 固定 MB；帧内可选 16×16 或 4×4 亮度预测区域，帧间有另一套宏块分区 | 变换分块不应与帧内／帧间预测分区画成同一层；Main 常规残差以 4×4 变换为基础 | 16×16 预测模式区内可有多个变换块；DC 系数还涉及专门处理 |
| HEVC | CU 决定编码区域；PU 描述预测区域 | TU 树单独组织残差；一个 CU 可含多个 TU，且可与 PU 的边界不完全重合 | 必须分别读 CU、PU、TU，不能把它们统称为“块” |
| AV1 | 分区树产生编码叶块，叶块承载帧内或帧间预测语法 | 残差按变换块处理；变换尺寸和进一步分割受块类型及规范限制 | 编码分区树不是变换树；矩形编码块也不意味着对应唯一同尺寸变换 |

帧内／帧间的差别会影响可选预测区域形状、运动信息和变换约束；但“预测如何分区”和“残差如何分块变换”仍是两个问题。阅读码流或画结构图时，建议用不同颜色或线型分别标出编码块边界、预测块边界和变换块边界。

## 读图或比较实现时的注意点

1. **区分编码块、预测块和变换块。** 它们回答的是不同问题：区域如何编码、预测模式覆盖哪里、残差在哪里一起变换。
2. **矩形不一定代表同一种能力。** AVC/HEVC 的帧间运动分区，与 AV1 的编码树分区或 HEVC 帧内 PU 不是一回事。
3. **不能只比较最大块尺寸。** AVC 固定宏块为 16×16；HEVC CTU 可更大；AV1 Superblock 最大 128×128，但这不表示每种标准都对最大区域做一次预测或变换。
4. **划分工具更丰富不自动等于码率更低。** 编码器需要权衡分区语法成本、预测残差、计算量和编码器搜索策略。
