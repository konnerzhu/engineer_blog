# AVC / HEVC / AV1 Main Profile：变换与量化详细对比

## 1. 比较范围：变换与量化是相邻但不同的步骤

本文比较 AVC / H.264 Main、HEVC / H.265 Main 和 AV1 Main 的普通有损编码路径，默认采用 **8 bit、4:2:0**。AV1 Main 也支持其他采样配置和位深，但这里固定条件以便比较。

```text
当前块 X 与预测块 P
        │
        └─ 残差 R = X − P
                │
                ├─ 变换：将空间残差表示成频率／方向系数 C
                │
                ├─ 量化：将 C 映射为较小范围的整数系数 Q
                │
                └─ 熵编码：将 Q、末非零位置和相关语法压缩进码流

解码端：熵解码 → 反量化 → 逆变换 → R̂ → 与 P 相加重建
```

**变换**决定残差用哪些基函数表示；**量化**决定这些系数的精度以及有多少系数会变成零。更换变换核不会自动改变量化步长；调整 QP / qindex 也不会改变变换块怎么划分。

本文聚焦三种标准 Main Profile 的变换／量化规则，不比较编码器的速度档、码率控制算法或视觉质量预设。具体编码器会联合搜索分区、预测、变换、量化、滤波和系数率失真代价；规范规定解码过程和语法，不规定编码器必须用哪一种搜索算法。

## 2. 一览：块尺寸、核和量化控制

| 维度 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 常规亮度变换块 | 4×4 | 4×4、8×8、16×16、32×32 | 19 种方形／矩形尺寸，最大到 64×64 |
| 变换块怎么划分 | 跟随宏块及残差语法；没有 HEVC 式 TU 四叉树 | CU 内独立的 TU 变换树，可混合不同尺寸 | Inter 有可变 Tx 树；普通 Intra 通常以一个编码块共享所选 Tx 尺寸 |
| 主要变换核 | 4×4 整数变换；Intra_16×16 另处理 DC | 常规 DCT-II；4×4 亮度 Intra 用 DST-VII | 受条件限制的 DCT、ADST、FLIPADST、Identity 等组合 |
| 量化控制值 | 8 bit 下 QP 0～51 | 8 bit 下 QP 0～51 | `base_q_idx` 0～255，再由 plane／DC-AC／块级调整导出量化值 |
| 系数频率加权 | Main 通常使用标准缩放因子；自定义缩放列表受 Profile／语法约束 | 可启用 Scaling List，对不同频率系数加权 | 可启用 quantization matrix，对变换位置加权 |
| DC 特殊处理 | Intra_16×16 亮度、4:2:0 色度有二级 DC 变换 | 统一放入 TU 变换树处理；4×4 亮度 Intra 核不同 | DC 使用独立量化值；变换类型和尺寸决定系数处理 |
| 变换旁路／无损 | 需结合规范条件理解；Main 的常规路径不是无损 | 可在相应语法开关和块条件下使用 Transform Skip / Transquant Bypass | Lossless 有专门条件和变换处理规则；不能只看 `qindex=0` 的字段名称 |

需要特别避免直接比较参数的数值：**AVC 的 QP=30、HEVC 的 QP=30、AV1 的 qindex=30 并不表示相同量化强度或相同质量。** AVC 与 HEVC 的 QP 标尺具有相似的对数步长关系；AV1 使用自己的索引到量化值映射表。

## 3. AVC Main：固定 4×4 整数变换与块级 QP

### 3.1 变换结构

AVC Main 的普通亮度残差主要使用 **4×4 整数变换**。它是 DCT 思路的整数实现，便于编码端与解码端以规范的整数加乘、移位和舍入得到一致结果。AVC Main 不启用 High Profile 引入的普通 8×8 变换工具。

宏块的预测区域可以比变换块大很多：例如 `Intra_16×16` 的预测覆盖 16×16 亮度区域，但残差仍由 4×4 块处理。预测块大小、变换块大小、熵编码的系数块是相关但不同的层级。

AVC Main 有两处需要单独看待的 DC 流程：

1. **Intra_16×16 亮度**：各 4×4 残差块的 DC 系数组成 4×4 矩阵，再做二级 Hadamard 类 DC 变换；AC 系数仍按原来的小块路径处理。
2. **4:2:0 色度**：每个 8×8 色度预测块分成四个 4×4 残差块，其 DC 系数组成 2×2 矩阵，进行对应的二级 DC 变换。

所以，“AVC 把 16×16 残差直接做一次 16×16 DCT”是错误的；预测区域可以是 16×16，普通主变换仍以 4×4 为基础，DC 另有集中变换路径。

### 3.2 QP 与量化

在 8 bit 下，AVC 亮度 QP 的常见范围为 **0～51**。QP 每增加 6，量化步长大致翻倍；QP 除以 6 的余数决定一组周期性整数缩放因子，商决定主要的移位尺度。规范将这些整数操作与反量化步骤配套定义，编码器和解码器必须得到相同重建值。

QP 首先在 slice 层建立，再可通过宏块的 QP delta 改变；Cb、Cr 的 QP 会经各自偏移和色度 QP 映射推导。不要把亮度 QP 直接当成每个色度分量最终使用的数值。

Main Profile 的普通路径以标准缩放关系为基础。H.264 还存在 Scaling List 等语法／工具，但它们的可用条件依 Profile 与参数集语法而定；比较 Main 时不能把其他 Profile 的 8×8 变换和自定义矩阵选项不加区分地算进来。

### 3.3 变换和量化的关系

4×4 变换把局部残差拆成 16 个系数；通常低频系数更大、更重要，高频系数更容易在量化后归零。对 Intra_16×16 或色度的 DC 二级变换，会改变 DC 能量在小块之间的表示，因此 DC 的量化和系数语法不能与普通 AC 系数完全混为一谈。

AVC Main 可使用 CAVLC 或 CABAC 熵编码，具体由参数集控制。即使两个候选变换后保留相同数量的非零系数，系数位置、幅值和上下文不同，最终码率仍可能不同。

## 4. HEVC Main：可变大小 TU、DCT-II / DST-VII 与 QP 分组

### 4.1 变换单元和尺寸

HEVC 将编码树 CU、预测单元 PU、变换单元 TU 分开。TU 树可以在同一 CU 内继续划分残差：例如一个较大的预测区域可以共享预测模式，但残差被分成多个不同尺寸的 TU。Main 的普通亮度 TU 最大为 32×32，尺寸为 4、8、16、32 的二次幂边长；具体可用尺寸仍受 SPS、CU、帧内／帧间类型等条件约束。

这种设计将“预测运动／模式区域”和“残差统计区域”解耦：若一片区域共享预测，但其中某一部分残差细节多，编码器可以继续划分那一部分 TU，而不必完全改写整个预测区域的模式归属。

### 4.2 变换核

- 常规 TU 使用 **DCT-II** 类整数变换。
- **4×4 亮度帧内 TU** 使用 **DST-VII**，以适配帧内预测残差的局部边界特性。
- 色度和帧间块遵循各自的规范条件，不可把 4×4 亮度帧内的 DST 规则套到所有 4×4 TU。
- 在相关开关和尺寸条件允许时，可以使用 **Transform Skip**，不执行常规空间变换；Transquant Bypass 是另外的旁路路径。

Transform Skip 不等于无损：它只是跳过常规变换，量化仍可能丢弃或改变系数。只有适用的旁路／量化条件同时满足时，才可能形成无损编码路径。

### 4.3 QP、QP delta 和 Scaling List

8 bit HEVC Main 的亮度 QP 范围同样通常是 **0～51**，每增加 6 个 QP 单位，量化步长按约两倍关系增长。HEVC 可在图像和 slice 的基准上定义 QP，再通过 CU 的 QP delta 在量化组内调整；Cb、Cr 还可加入各自偏移并经色度 QP 表推导。

HEVC 可以使用 **Scaling List** 为不同变换尺寸和频率位置设置权重。量化矩阵不是新的变换核：它改变各系数的相对量化尺度，而 DCT-II／DST-VII 决定残差投影到哪些基函数上。

变换树和 QP 粒度互相影响：划分 TU 会改变残差分组和可用变换尺寸；QP delta 会改变相应量化区域的系数精度。编码器通常用率失真搜索一起比较它们，而非先固定一种再独立调另一种。

## 5. AV1 Main：19 种 Tx 尺寸、受限的变换类型集合与 qindex

### 5.1 尺寸和树结构

AV1 定义 **19 种方形与矩形 Tx 尺寸**，从 4×4 到最大 64×64；也有 1:2、1:4 等长宽比的矩形尺寸。不是每个块都能使用所有尺寸，具体集合取决于块尺寸、帧头 TxMode、帧内／帧间模式以及 transform tree 规则。

- **普通 Intra**：编码块选择变换尺寸后，通常由同一编码块内的变换块共享该尺寸；需要局部适应时，可进一步改变编码块分区。
- **Inter**：可用递归可变 Tx 树在块内细分变换尺寸，更贴合运动补偿后的局部残差。
- **大变换限制**：有 64×64 Tx 类型不代表码流能任意携带完整的 64×64 高频系数；AV1 对每个维度最多处理 32 个变换系数位置，64×64 Tx 的有效系数区域至多为左上 32×32。

变换块与编码块的几何尺寸不是同一个概念。矩形 Tx 的合法分裂也依据规范表推导，不能假设所有宽高可以任意对半切。

### 5.2 变换类型

AV1 的逆变换类型包含 DCT、ADST、FLIPADST 的水平／垂直组合，另有二维或一维 Identity 等类型。规范列出 16 个总体类型，但**某一个块实际可选的子集**会随 Intra / Inter、Tx 尺寸和语法条件改变。很多大尺寸仅允许少量类型；不能把“标准定义了 16 种”说成“每个块都可自由选 16 种”。

这种组合允许变换方向与块内纹理方向更匹配。例如，残差主要沿一个方向变化时，一维或非对称变换可能更合适；代价是编码器要评估更多合法变换候选，解码器也要实现对应逆变换。

### 5.3 qindex、平面差异和量化矩阵

AV1 使用帧级 `base_q_idx`，8 bit 语法字段可表示 0～255。它不是线性量化步长，也不是 H.264／HEVC 的 QP：规范通过查表导出 DC、AC 量化值，再结合位深、变换尺寸、平面和系数位置执行整数反量化。

AV1 可对 Y、U、V 的 DC 和 AC 使用不同的 delta quantizer；语法也支持块级 delta-Q 与 segmentation 的替代量化特征。其作用是让不同区域或分量在相同帧基础值上使用不同量化强度。

可选的 **Quantization Matrix** 进一步按变换系数位置缩放量化值，通常可理解为对频率位置加权。它和变换类型是两种独立决定：变换核决定基函数，量化矩阵决定不同系数位置的量化权重。

AV1 通过帧／块参数派生量化值和 DC／AC 差异。比较两个 AV1 块时，仅看 `base_q_idx` 可能不够：还应检查 delta-Q、分段特征、平面 DC/AC 偏移、矩阵级别和实际 Tx 尺寸。

## 6. 三种量化标尺不能按数字直接横比

| 项目 | AVC Main | HEVC Main | AV1 Main |
|---|---|---|---|
| 基础量化值 | QP | QP | qindex |
| 8 bit 基础范围 | 0～51 | 0～51 | 0～255 |
| 步长标尺关系 | QP +6，步长约翻倍 | QP +6，步长约翻倍 | 查表映射；不是 AV1 qindex +6 就对应翻倍 |
| 色度处理 | QPc 映射及 Cb/Cr offset | 色度 QP 表及 Cb/Cr offset | U/V 独立 DC/AC delta 可选 |
| 空间自适应量化信令 | 以宏块 QP delta 为主 | 以 CU / QG QP delta 为主 | 可用 delta-Q 与 segment alt-Q 等机制 |
| 频率相关权重 | Main 受 Profile 限制，常见是默认缩放关系 | 可选 Scaling List | 可选 Quantization Matrix |

一个有用的概念式是：

```text
有效量化强度 ≈ 基础量化值
              + 平面／DC-AC 偏移
              + 块级或分段调整
              + 频率位置加权
```

这只是帮助理解的分解，不是三个标准共用的数学公式。要比较实际画质，需要分别校准编码器的质量设置或对齐目标码率，再看重建效果；把相同的 QP 数字或 `qindex` 数字直接填进对比表没有可比性。

## 7. 为什么变换和量化必须联合考虑

变换让能量集中到少量系数的机会增加，但它是否合适取决于残差形状。量化则进一步决定保留哪些系数、保留到什么精度。编码器可以用下式概括候选选择：

```text
J = D(原始块, 重建块) + λ × R(分区、变换类型、QP／qindex、系数及其他语法)
```

其中 D 是失真，R 是码率，λ 是编码器的率失真权衡参数。下面仅是可能的选择，不是编码规范强制结论：

### 场景 A：大面积平滑渐变

较大变换可能把残差集中到少量低频系数，减少系数描述成本。若渐变里叠加局部纹理或边缘，大变换可能产生更多难量化系数；小块或另一种方向核反而可能更划算。

### 场景 B：细线、文字笔画或强方向纹理

AVC Main 主要通过 4×4 变换和宏块分区适配。HEVC 可在 CU 中继续分 TU，并用较大或较小变换处理不同残差区域。AV1 有多种矩形 Tx 尺寸和方向核，但候选可用性受规则限制。更复杂的核只有在它节省的系数码率超过变换类型／块划分语法成本时才值得选择。

### 场景 C：高频噪声或随机纹理

高频系数不一定可被紧凑表示。增大量化可能把更多系数清零，但会损失纹理；减小量化能保留细节，也会提高码率。变换和量化选择要结合视觉失真权重，不能只看残差平方和。

### 场景 D：色度与亮度的视觉重要性不同

三种标准都允许或能推导分量相关量化参数；AV1 进一步明确区分 U/V 的 DC 和 AC 量化 delta。编码器可以为色度分配不同于亮度的量化强度，但实际效果仍需考虑采样格式、显示尺寸和内容。

## 8. 解码器重建为什么必须精确

变换、量化和逆变换都涉及定点整数运算、舍入、剪裁和系数范围。规范定义的不是抽象浮点 DCT，而是特定输入范围下的整数解码过程。即使编码端内部以更高精度或浮点近似搜索候选，最终必须形成规范允许的量化系数和确定性的重建值。

对帧间编码而言，反量化和逆变换后的残差会与预测块相加；重建结果还会参与后续环路滤波并成为参考帧。若不同解码器对反量化、逆变换或舍入实现不同，差异可能逐帧积累成预测漂移。因此，系数的扫描顺序、变换核、量化表和整数舍入都是码流兼容的一部分。

## 9. 常见误区

| 容易误写的说法 | 更准确的说法 |
|---|---|
| AVC Main 有 8×8 变换 | AVC Main 常规路径以 4×4 整数变换为主；8×8 变换是其他 Profile 的工具 |
| Intra_16×16 就意味着 16×16 DCT | 预测块可为 16×16，残差仍分成 4×4 变换块，DC 另有二级变换 |
| HEVC 一个 CU 只有一种 TU 大小 | CU 内可用 TU 树细分，形成多个尺寸的残差叶块 |
| AV1 有 16 种 Tx，所以每个块都能选 16 种 | 标准列出总体变换类型，但各模式和尺寸允许的子集不同 |
| 64×64 Tx 等于 64×64 所有频率都可编码 | Tx 尺寸与可传系数区域是不同限制，需按 AV1 规范解读 |
| QP 或 qindex 越大，质量就按线性比例下降 | QP 和 qindex 是不同标尺；感知质量还取决于变换、预测、量化矩阵和内容 |
| QP=30 等于 qindex=30 | 两者范围和映射不同，数值不能直接对齐 |
| Transform Skip 就是无损 | 跳过变换不代表跳过量化；无损需满足专门旁路与量化条件 |
| 量化矩阵就是变换矩阵 | 变换矩阵定义频率基；量化矩阵改变不同系数位置的量化权重 |
